# 王陆807 雅思单词听写练习

基于王陆《807雅思词汇》的在线听写练习工具。按章节生成独立的听写页面，支持乱序听写、真人美音发音、错题记录、Excel 导出，纯静态页面，可部署在 GitHub Pages。

## 在线使用（推荐）

本项目为纯静态页面，已托管在 GitHub Pages，浏览器直接访问，无需任何本地环境：

**访问地址：<https://sammi-code-cloud.github.io/-807/>**

1. 打开首页（章节导航页）
2. 在「快速跳转」区选择章节 → 选择页数 → 点击「开始听写」；或直接点击下方章节卡片进入
3. 手机、电脑浏览器均可直接使用

> 首次部署需在仓库 Settings → Pages → Source 选择 `main` 分支根目录并保存；之后每次 `git push` 自动更新，刷新页面即可看到新章节。

## 本地预览（可选）

如果想在推送前本地检查页面效果，用任意静态服务器打开项目根目录即可，例如：

- VS Code 安装 Live Server 插件，右键 index.html → Open with Live Server
- 或命令行：`python -m http.server 8000` / `npx serve`

> 注意：不要双击 html 用 file:// 协议直接打开，音频可能无法播放；日常使用走 GitHub Pages 就不存在这个问题。

## 听写页面使用方法

1. 进入章节页面后自动乱序开始，每题自动播放美音
2. 听音后在输入框输入单词，**按回车提交判分**
3. 答错不跳题：页面显示你的输入 + 标准答案 + 考点提示，**再按一次回车才进入下一题**（答对同样需回车切题）
4. 页面实时统计：进度、正确数、错误数、正确率
5. 按钮功能：
   - 🔊 **重听当前**：重新播放当前单词读音
   - 👁 **显示标准答案**：随时查看当前单词的答案、释义和提示
   - 🔄 **重置&重新乱序**：清空记录，重新打乱顺序开始
   - 📥 **导出Excel**：练习结束后启用，导出含对错明细和汇总行的 .xlsx 文件
6. 全部完成后展示对错清单（绿色✅答对 / 红色❌答错并显示错误输入）
7. 页面底部是本章完整单词库，点击任意单词可播放发音

**推荐练习节奏**：先在底部单词库通读一遍（点击听发音）→ 开始乱序听写 → 完成后导出 Excel → 针对错词隔天点「重置&重新乱序」再刷一遍。

## 新增章节流程

1. 在 `words\chapter章节号\` 文件夹下新建 txt 文件（如 `words\chapter8\chapter8(45-46).txt`，章节文件夹不存在则先创建），每行填一个单词
2. 打开 `prompt\提示词模板.md`，复制提示词正文，替换 `{章节文件名}` 后发给 AI
3. AI 会完成三件事：
   - 在 `html\` 下生成同名听写页面（自动补全音标、中文释义、考点提示）
   - 在 `index.html` 的 `chapterList` 数组中登记新章节
   - 在 `progress\progress.md` 进度表中追加导入记录
4. 提交推送：

```bash
git add words/ html/ index.html
git commit -m "新增 chapter8(45-46) 听写页面"
git push
```

5. 刷新 GitHub Pages 首页即可看到新章节

`chapterList` 登记格式：

```js
const chapterList = [
    {chapter: 7, pages: "43-44", file: "chapter7(43-44).html", count: 55},
    // 新章节在此追加
];
```

## 技术说明

- 单文件 HTML，CSS/JS 全部内嵌，无后端依赖
- 发音：谷歌词典牛津真人美音 mp3 直链（禁用浏览器 TTS），带失败回退（us_1 → us_2 → 复数回退单数）
- Excel 导出：SheetJS（xlsx）CDN，WPS/Excel 可直接打开
- 电脑、手机自适应

## 注意事项

- 带连字符的复合词（如 low-risk）谷歌词典可能没有对应 mp3，播放会静默失败，以拼写练习为主
- AI 补全的音标和释义可能偶有偏差，生成后建议抽查
