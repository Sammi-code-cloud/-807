# 雅思单词听写页面生成 · 可复用提示词模板

> 用途：根据 words 目录下某章节的单词 txt 文件，生成"单词展示 + 乱序听写练习 + Excel导出"的单文件 HTML，输出到 html 目录。
> 复用方式：把下面【提示词正文】整段复制发给 AI，替换 `{章节文件名}` 即可。

---

## 提示词正文（直接复制使用）

```
帮我模仿 html\chapter7(43-44).html、按照需求.md 的规则，根据 words\{章节文件名}.txt 里的单词列表，
生成对应的 {章节文件名}.html，放在 html 文件夹下；
并在 index.html 的 chapterList 数组中登记这一章（chapter 章节号、pages 页数、file 文件名、count 单词数）。

具体要求：
1. txt 文件每行一个单词（只有单词本身），请为每个单词自动补全：
   - phonetic：英式音标
   - zh：中文释义（含词性，如 n. / v. / adj.）
   - tip：雅思听写考点提示（拼写陷阱、易混词、场景、复数考点等）
2. 单词数据统一放在 JS 数组 wordListRaw 中，每项格式：
   {"w":"单词","phonetic":"音标","zh":"中文释义","tip":"考试提示"}
3. 页面结构（与 html\chapter7(43-44).html 一致）：
   - 顶部红色提示：请通过 GitHub Pages 或 http 服务访问，不要用 file 协议双击打开
   - 浅黄色章节说明块：总结本章单词的拼写陷阱分类（双写字母/不发音字母/复数/易混词/派生词）
   - 乱序听写面板：进度、正确数、错误数、正确率实时统计
   - 练习结束后的对错清单（绿色✅答对 / 红色❌答错并显示用户错误输入）
   - 底部完整单词库列表，由 wordListRaw 动态渲染，点击整行播放发音
4. 听写交互硬性规则：
   - 单词乱序，每题自动播放美音，支持按钮重听
   - 回车提交判分；答错不自动跳题，错误信息（用户输入+标准答案+tip）停留页面，
     必须再按一次回车才切下一题；答对同样需回车切题
   - 提供按钮：重听当前、显示标准答案、重置&重新乱序、导出Excel
   - 输入框 autocomplete="off"，练习结束后禁用
5. 发音规则：
   - 禁止浏览器 TTS，统一使用谷歌词典牛津真人美音直链：
     https://ssl.gstatic.com/dictionary/static/sounds/oxford/{单词}--_us_1.mp3
   - 增加失败回退：us_1 失败尝试 us_2；复数词无音频时回退播放单数形式
   - audio 标签隐藏，切换单词时停止上一条音频
6. Excel 导出（SheetJS CDN：https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js）：
   - 字段：序号、标准答案单词、中文释义、是否正确、用户输入、考点提示
   - 末尾追加汇总行（总题、正确、错误、正确率），设置合适列宽，WPS/Excel 可直接打开
   - 文件名：{章节文件名}听写练习结果.xlsx
7. 技术约束：单文件 HTML，CSS 内嵌，仅 CDN 外部依赖，无后端；
   电脑手机自适应；单词条目 hover 浅蓝背景；英文单词蓝色加粗；tip 红色小字；
   白色卡片容器+柔和阴影。
8. 输出完整全部 HTML 代码，不要省略。
```

---

## 使用步骤

1. 在 `words\` 文件夹下新建 txt 文件（如 `chapter8(45-46).txt`），每行填一个单词
2. 复制上面提示词正文，把 `{章节文件名}` 替换为实际文件名（如 `chapter8(45-46)`）
3. 发给 AI，生成的 html 保存到 `html\` 文件夹，同时 index.html 的 chapterList 数组会登记新章节
4. 推送到 GitHub，通过 GitHub Pages 访问首页选择章节即可（无需本地服务）

## 注意事项

- **通过 GitHub Pages（或任意 http 静态服务）访问**，不要双击 html 用 file:// 协议打开，否则音频可能无法播放
- 带连字符的复合词（如 low-risk）谷歌词典可能没有 mp3，播放会静默失败，以拼写练习为主
- 生成后建议抽查几个单词的音标和释义是否准确，AI 补全内容可能偶有偏差
- 参考文件：`index.html`（章节路由导航页）、`需求.md`（原始需求）、`html\chapter7(43-44).html`（听写页面模板示例）
